# Uma demo Kubernetes com Istio

**Status:** accepted. A palestra terá uma única demo Kubernetes ao vivo, de inferência com Istio, Gateway API, GAIE, `HTTPRoute`, `InferencePool`, EPP e `llm-d-inference-sim`: três réplicas de `fast`, com TTFT menor, e um pool `quality`, com TTFT maior. Ambos retornam `usage`. O header `X-Demo-Pool` seleciona a `HTTPRoute`, cujo `backendRef` aponta para o `InferencePool`; o corpo permanece na API OpenAI-compatível. A demo deve rodar offline com imagens e artefatos pré-carregados no Kind. O cluster é preparado no ensaio; no palco, executam-se somente as chamadas de inferência. O mock foi retirado: o simulador é a única fonte de comportamento de inferência. Egress/AI Gateway fica separado e adiado, enquanto RDMA é explicação técnica até haver hardware validado; isso concentra a mensagem em Istio e reduz risco de palco.
